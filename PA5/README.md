Animal Facts API that runs via AWS Console EC2 Hosting

Steps for running locally:
1) Run app.py with debugging
2) Open powershell window paralell to the debugging console
3) Navigate to PA5
4) Run Tester with "python appTester.py"
5) Gain knowledge about animals

Steps for running via curls:
info: curl 3.144.87.252/info
facts: curl --header "Amount: 15" 3.144.87.252/fact
