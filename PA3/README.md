Instrucitons:
Start node 3 in its own shell first with the command: python node.py 8080 8082 4 0 3
Next, start node 2 in a new shell with the command: python node.py 8082 8081 3 0 2
Finally, start node 3 in a new shell with the commmand: python node.py 8081 8080 5 1 1

--When you run these commands, the packet will be sent around indefinitely, so you'll need to halt the program manually with crtl+c.--
